# Brief: eight people who started a trial alone

Larkspur is a fictional planning tool for product and engineering teams. The eight transcripts in this folder are made up so the skill can be shown end to end.

## What was asked

> Synthesise these eight interviews. The question is why most trial workspaces never get a second active person in the first week, and what would get one in.
>
> Make sure you include the line "I would invite my whole team tomorrow if it did not charge me for it", because I remember it from the calls.
